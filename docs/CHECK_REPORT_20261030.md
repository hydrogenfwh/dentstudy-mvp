# 齿间网站检查报告（2026-10-30，北京时间）

## 检查结论

线上首页和健康接口可访问。Flutter 静态分析通过；前端完整测试 173 项通过，后端 109 项测试在带 cryptography 的本地运行环境中通过。自动测试使用模拟账户、临时数据库和模拟支付平台，不能替代真人端到端验收，也不能证明网站完全没有问题。

本次前端修复已发布到 `20261030-audit-r1`。上线后公网主脚本 SHA-256 与本地构建一致，网站及后端服务状态正常；前一版网页仍保留。后端程序未在本次发布中变更。

## 本次发现并修复

1. 英文注册时，两次密码不同的提示仍显示中文。已将该提示按当前语言显示，并新增界面回归测试，验证切换英文、打开注册、输入不同密码后的实际提示。
2. 月卡用户用过首月优惠后，英文界面中的“每月 6.9 元、手动续费”说明未翻译。已补充翻译及验证，价格和续费方式未改变。
3. 练习完成后的汇总页仍有多处中文。已补充完成数量、正确率、用时、复习提示和操作按钮的英文显示，题干及用户输入仍保持原文。
4. 两项外观测试因语言切换后返回按钮的系统提示从英文变成中文，旧测试按英文提示找按钮而失败。确认页面中有实际返回按钮后，已改为直接查找并点击返回按钮；相关测试通过。这是测试定位方式的问题，不是已确认的线上导航故障。

## 已知限制和后续建议

- 英文模式尚不是全站完整翻译：代码审查仍能看到批量练习、速刷、部分学校资料、服务规则和错误提示中的中文。医学题干、选项、资料正文及用户内容按现有约定保留原文；界面文案仍需持续补齐。此次并未逐页证明所有英文页面完整。
- 生产环境只做了只读健康与匿名权限检查，没有使用真实账户创建订单、发消息或修改学习记录，也没有在真实手机和 Safari 上逐项录屏操作。自动测试不能完全覆盖真实浏览器、网络波动或第三方支付情况。
- 如需验收真实支付，应使用明确约定的测试账号与小额订单，逐步核对付款、回调、会员开通、系统消息与账单；当前不应把模拟测试当成真实交易成功的证据。
- 检查项目是当时工作区的代码和运行中的线上版本；后端的本地测试结果不单独证明线上后端文件与本地完全相同。
